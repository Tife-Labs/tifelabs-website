# 🚀 TifeLabs Website

Welcome to the official source code for **[TifeLabs](https://tifelabs.vercel.app)** — a modern, high-performance web platform designed to showcase our software engineering, AI integration, and cloud infrastructure services.

---

## 🌟 About The Project

This website serves as the primary digital front door for TifeLabs. Built with performance, accessibility, and smooth user experience in mind, it leverages Next.js 14, Tailwind CSS, and Framer Motion to deliver a fast, responsive, and reliable experience across all devices.

### 🛠️ Key Features

* **⚡ Next.js 14 App Router:** Takes full advantage of server components, optimized routing, and fast builds via Turbopack.
* **🎨 Modern UI & Motion:** Responsive designs styled with Tailwind CSS, animated seamlessly using Framer Motion.
* **🛡️ Type Safety & Form Validation:** Clean contact form handling backed by React Hook Form, Zod validation, and Formspree integration.
* **📊 Analytics & Insights:** Integrated with Google Analytics (GA4) and Vercel Analytics for tracking user interaction.
* **🔍 SEO & Social Sharing:** Fully optimized OpenGraph metadata, Twitter cards, and semantic HTML for search visibility.

---

## 🧰 Tech Stack

* **Framework:** [Next.js 14](https://nextjs.org/)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons & Primitives:** Lucide React, Radix UI Slot, Class Variance Authority
* **Form Backend:** Formspree
* **Hosting:** [Vercel](https://vercel.com)
